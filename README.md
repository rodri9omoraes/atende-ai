# Atende Aí 🏥

Sistema de aviso em tempo real entre recepção e assistente social para sala de atendimentos.

## 🚀 Funcionalidades

- Comunicação em tempo real via Socket.io
- Aplicativo desktop desenvolvido com Electron
- Widget de status sempre visível no canto da tela
- Inicialização automática com o Windows
- Reconexão automática caso o servidor da recepção esteja desligado

## 📦 Como rodar o projeto (Desenvolvimento)

1. Clone este repositório: `git clone <url-do-seu-repo>`
2. Instale as dependências: `npm install`
3. Inicie o aplicativo: `npm start`

## 🛠️ Tecnologias Utilizadas

- [Electron](https://www.electronjs.org/)
- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/)
- [Socket.io](https://socket.io/)
